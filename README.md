# RYUGEAR — Level Up Your Game

Award-winning-style e-commerce homepage for **RYUGEAR**, India's premium esports peripherals store (keyboards, mice, mousepads, headsets/IEMs, keycaps). Tagline: *"Level Up Your Game."*

Built as a flagship gaming-hardware brand site — inspired by Razer / ASUS ROG / Awwwards-tier design — with a real hero product sequence instead of flat photos.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- GSAP + ScrollTrigger
- Lenis (smooth scroll)
- Framer Motion (UI transitions)
- React Three Fiber + drei (3D scenes)
- oxlint

## Getting started

```bash
npm install
npm run dev      # dev server
npm run build    # production build
npm run lint     # oxlint
```

## Scripts (dev tooling)

- `scripts/verify.mjs` — automated hero-section verification (20 checks)
- `scripts/screenshots.mjs` — Playwright visual screenshots
